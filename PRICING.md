# Smart Pet Agent — Pricing

> **Core is MIT, free forever.** Pricing only applies to optional add-ons that fund development. No feature is paywalled in the open-source build.

## Free — MIT Open Source

- **$0** — everything in this repo stays MIT. Clone, build, modify, ship your own version.
- No telemetry, no ads, no tracking. Same local-first build whether you donate or not.
- Includes: desktop (Electron), CLI, TUI, Android APK (sideload), multi-provider AI, memory, permissions/audit, `default-nyc-orb` pet, Custom Pet Creator MVP (`.smartpet` export/import).

## Planned Paid Add-Ons (post-v1.0.0, not active at v1.0.0)

| Add-on | Price (planned) | Notes |
|---|---|---|
| **Premium Pet Packs** | $0.99–$4.99 per `.smartpet` pack | Curated packs via in-app Pack Store. The `.smartpet` format is already exported by the Creator MVP — the store is a UI layer over manual import. |
| **Managed Cross-Device Sync** | ~$2.99/mo (planned) | Optional hosted sync; encryption key never leaves your device (backend sees only ciphertext). |
| **Premium Support** | Custom | For orgs deploying Smart Pet Agent internally. |

## What Pricing Will Never Do

- No code becomes proprietary; core stays MIT.
- No SDK or baked-in credential is added to upsell.
- No affiliate fees or referral schemes.
- No dual-license.

See `docs/Monetization.md` for the full funding model and `docs/PLAY_CONSOLE_DATA_SAFETY_v1.0.0.md` for privacy.
