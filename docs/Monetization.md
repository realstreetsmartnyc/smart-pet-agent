# How Smart Pet Agent is funded

Smart Pet Agent is open-source (MIT) and free to use. The project is funded by:

1. **Donations and sponsorships** — GitHub Sponsors, Open Collective, Ko-fi.
   This is the only funding model active at v1.0.0.
2. **Premium pet packs** — curated `.smartpet` packs sold through an in-app
   store (planned post-v1.0.0). The `.smartpet` format is the one exported by
   the Custom Pet Creator MVP; the store is a UI layer over the existing import.
3. **Managed cross-device sync** — an optional hosted service for users who
   want their pet state and chat history to follow them across devices
   (planned post-v1.0.0). The encryption key never leaves the user's device;
   the backend sees only ciphertext.
4. **Premium support contracts** — paid support for organizations deploying
   Smart Pet Agent internally.

## What monetization does NOT do

- **No code becomes proprietary.** Everything in this repo stays MIT.
- **No telemetry or ads.** The v1.0.0 build is the same local-first, no-tracking
  build whether you donate or not.
- **No feature is paywalled in the open-source build.** The Pack Store UI links
  to the hosted store; users can ignore it and import `.smartpet` files manually.
- **No dual-license.** The core remains MIT for everyone.
- **No affiliate fees or referral schemes.** Those would violate the
  "no baked-in credentials or third-party project connections" rule.
